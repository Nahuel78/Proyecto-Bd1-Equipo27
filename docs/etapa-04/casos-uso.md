# Etapa IV: Consultas y Casos de Uso

Este documento resume los casos de uso implementados para la extracción, reporte y análisis de información en la base de datos BD\_VENTAS.

## Estructura de Documentación

Cada uno de los siguientes archivos detalla el requerimiento de negocio, las tablas involucradas, el código SQL desarrollado y el análisis de resultados:

1. \[Comprobante de Venta\](./comprobante-venta.md) \- Emisión y consolidación de comprobantes y detalles de compra.  
2. \[Informe General de Ventas\](./informe-ventas.md) \- Reporte de operaciones y montos acumulados por cliente mediante subconsultas.  
3. \[Consulta Avanzada de Stock\](./consulta-avanzada.md) \- Control de inventario crítico y productos bajo el stock mínimo.
